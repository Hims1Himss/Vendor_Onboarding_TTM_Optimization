# SOP: Standardized Vendor Intake & Compliance Checklist

**Owner:** Category Manager (intake) → Central Compliance (verification)
**Goal:** Submit a complete, first-time-right document pack so there is no rework loop.

## Stage 1: Category intake (Day 0-1) - Category Manager
- [ ] Merchant registered on the single intake form (no email attachments)
- [ ] Category and sub-category confirmed; regulated-category flag set (Electronics, Beauty, Grocery)
- [ ] Commercial terms and brand authorization letter attached (if branded goods)

## Stage 2: Document pack completeness check (Day 1) - Category Manager, before handoff
- [ ] Business registration / incorporation certificate: legible, not expired
- [ ] Tax registration (GST) certificate: number matches business name
- [ ] PAN of business/proprietor: name matches GST record
- [ ] Cancelled cheque or bank statement: account name matches legal entity
- [ ] Address proof: dated within last 3 months
- [ ] Category licenses (FSSAI for Grocery, BIS for Electronics, cosmetics license for Beauty)
- [ ] All names/addresses consistent across documents (the top cause of rejection)

## Stage 3: Handoff (Day 1) - hard rule
- Pack is handed to Central Compliance ONLY when Stage 2 is 100% ticked.
- Handoff logged with timestamp in the tracker. **SLA: Compliance picks up within 1 working day.**

## Stage 4: Verification (Day 2-4) - Central Compliance
- [ ] Documents verified against source registries
- [ ] Any rejection returned with ONE consolidated reason list (no piecemeal rejections)
- [ ] Approved / rejected status updated in tracker same day

## Stage 5: Catalog setup & go-live (Day 4-8) - Category Manager
- [ ] Catalog template shared on approval day
- [ ] First listings QC'd and live

## Escalation
| Trigger | Action |
|---|---|
| Handoff pickup > 1 working day | Escalate to Compliance Lead |
| Total TTM > 14 days | Flag on weekly scorecard as SLA breach |
| No movement for 25+ days | Mark "Stuck", owner assigned in weekly review |
